# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres
to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.0] - 2026-10-24

### Changed
- **Requires Reflex ≥ 0.10.0** and **Python ≥ 3.11** (Reflex 0.10 dropped Python 3.10).
- Build backend switched from `setuptools` to `hatchling` + `hatch-reflex-pyi`,
  following the official Reflex component template: `reflex component build` no
  longer exists in Reflex 0.10, and `.pyi` stubs are now generated by `uv build`.
- Source moved from `custom_components/` to `src/` (the layout `hatch-reflex-pyi`
  requires). The import path `reflex_jupyter_renderer_react` is unchanged.
- Demo app requirements bumped to `reflex>=0.10.0`.
- Docs (README, specs) updated to reflect the actual npm coordinates
  (`@iomete/jupyter-renderer-react@1.0.1`, tag `JupiterNotebookViewer`).

### Added
- GitHub Actions: `ci.yml` (ruff + pytest on Python 3.11–3.14, build, demo compile)
  and `publish.yml` (PyPI trusted publishing on `v*` tags).

### Fixed
- Component contract test asserted the wrong React tag; ruff E402 in tests.

## [0.1.0] - 2026-06-18

### Added
- Initial release.
- `JupyterNotebookViewer` Reflex component wrapping `jupyter-renderer-react`.
- Full prop coverage: `notebook`, `theme`, `show_cell_numbers`, `show_outputs`,
  `collapsible`, `copyable`, `class_names`, `styles`, `fetch_options`.
- Event handlers: `on_file_load`, `on_file_error`, `on_error`.
- Convenience constructors: `JupyterNotebookViewer.from_url`, `.from_json`.
- Dependency-free notebook builders (`Notebook`, `CodeCell`, `MarkdownCell`,
  `RawCell`, output helpers) and `load_notebook` / `notebook_from_url`.
- Demo Reflex app under `jupyter_renderer_react_demo/` covering every feature.
- Spec-Driven Design artifacts under `specs/` (PRD, architecture, API,
  data model, implementation plan with phases and tasks).
- Test suite under `tests/`.
